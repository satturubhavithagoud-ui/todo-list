# todo-list
A SIMPLE TO-DO LIST APPLICATION USING REACT AS FRONTEND AND DJANGO AS BACKEND.
# Todo App (React + Django)

## Features
- Add, edit, delete tasks
- REST API using Django
- Responsive UI using React

## Tech Stack
- React (Vite)
- Django REST Framework
- SQLite

## How to Run

### Backend
cd backend_root
python manage.py runserver

### Frontend
cd frontend
npm install
npm run dev
